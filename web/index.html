Server

    
A simulated Apache/1.3.22 (Unix) running PHP 4.1.1 as a CGI binary. Every request starts a fresh PHP process; files under /var/www, /tmp and /etc persist.

    
    
    
    
    

      
      An emulated MySQL 3.23.49 server on /tmp/mysql.sock and port 3306, backed by SQLite. PHP's real mysql_* functions and client library talk to it. Any user/password is accepted (like --skip-grant-tables). Turn it off to get the classic "Can't connect to local MySQL server" error.
