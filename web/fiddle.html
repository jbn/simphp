Settings

    
Server settings belong to this fiddle. A simulated Apache/1.3.22 (Unix) runs PHP 4.1.1 as a CGI binary, one fresh process per request.

Link copied

    
  

  
  
The link is the fiddle: it carries a compressed copy of your files, and nothing is uploaded anywhere. Keep in mind:

  
    
    
  • It's a snapshot. Edits you make later don't reach it. Share again to send them.
    • 
    
  • Only text files travel. Images and other binary files are left out.
    • 
    
  • Server state stays here. MySQL databases, sessions, /tmp and cookies start fresh for whoever opens the link.
    • 
    
  • It opens as a new fiddle in their browser. Nothing syncs back to you.
